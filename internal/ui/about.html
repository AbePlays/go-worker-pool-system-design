About this little project

This is a background job system built in Go — not just to work, but to practice real system design thinking.

What's under the hood

  • PostgreSQL as the source of truth
  • Atomic job claiming with SKIP LOCKED
  • Retries with exponential backoff (Sleep, Webhook)
  • Idempotency keys for safe client retries
  • Backpressure: 429 when the queue (1000) is full
  • Three job types: Sleep, Webhook, Image
  • Schema managed via versioned migrations

Planned

  • Dead-letter queue with operator replay
  • Signed webhook payloads (HMAC)
  • Per-target throttling for slow endpoints

Tech stack

  • Go
  • PostgreSQL
  • Docker Compose
  • Plain HTML & CSS (no JavaScript)

Source

This project is open source. View it on GitHub.

Made for learning system design the hands-on way.
